Render Lifecycle

      
1
A qualifying event (e.g. App Launched) triggers the InApp campaign in CleverTap.

      
2
SDK downloads the HTML/CSS/JS payload. Enable the Enable JavaScript checkbox in the dashboard campaign.

      
3
Template renders inside a native WebView — WebView on Android, WKWebView on iOS.

      
4
CSS @keyframes animation plays automatically on load. No extra SDK config needed.

      
5
Button tap → JS bridge fires. Android: window.CleverTap.pushEvent(). iOS: webkit.messageHandlers.clevertap.postMessage().

      
6
CleverTap logs Notification Clicked with wzrk_c2a property — visible in campaign analytics.

      
7
Dismiss: Android calls dismissInAppNotification(); iOS handled automatically by the SDK.

      
Dashboard Setup

      
✓
Campaigns → InApp → Custom HTML → paste template → check Enable JavaScript → set trigger → publish.

      
✓
Use {{variable}} in HTML — CleverTap substitutes user profile / event properties at render time.
