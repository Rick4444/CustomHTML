Render Lifecycle

        
1
A qualifying event triggers the InApp campaign in CleverTap.

        
2
SDK downloads HTML/CSS/JS payload. Enable Enable JavaScript in the dashboard campaign.

        
3
Template renders in native WebView — WebView on Android, WKWebView on iOS.

        
4
CSS @keyframes animation plays automatically. No extra SDK config needed.

        
5
Button tap fires JS bridge. Android: window.CleverTap.pushEvent(). iOS: webkit.messageHandlers.clevertap.postMessage().

        
6
CleverTap logs Notification Clicked with wzrk_c2a visible in campaign analytics.

        
7
Dismiss: Android dismissInAppNotification(); iOS handled by the SDK automatically.

        
Dashboard Setup

        
✓
Campaigns → InApp → Custom HTML → paste template → check Enable JavaScript → set trigger → publish.

        
✓
Use {{variable}} — CleverTap substitutes user profile / event properties at render time.
